# Sonic Mania Plus Web

Sonic Mania Plus web port by Crunch Arcade / Crunchtop;

## Play

- GitHub Pages: https://hedgeplays2.github.io/Sonic-Mania-Plus-WEB/

## Use

Open the GitHub Pages link in your browser to play.

## Experimental modding

See [MODDING.md](./MODDING.md) for the browser mod formats and C++ WebAssembly runtime. The first visible C++ example is the [Super Speed Mod ZIP](./examples/super-speed-indicator/Super-Speed-Mod.zip); it proves the module lifecycle and browser badge host call, but does not change Sonic's movement speed.
